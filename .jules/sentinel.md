## 2025-02-13 - [DNS Rebinding Protection via Custom Resolver]
**Vulnerability:** The HTTP client in `hyperinfer-server` (`reqwest::Client`) used for outbound requests was susceptible to SSRF and DNS Rebinding attacks because it relied on synchronous pre-flight host validation or string prefix matching, which can be bypassed by an attacker rapidly changing DNS records (TOCTOU).
**Learning:** Using simple `starts_with` logic or validating a URL string before resolution is insufficient for robust SSRF protection when dealing with external, dynamic APIs.
**Prevention:** Always implement a custom `reqwest::dns::Resolve` trait to intercept and validate resolved IP addresses at the socket level asynchronously, and ensure HTTP redirects are explicitly disabled via `.redirect(reqwest::redirect::Policy::none())` to prevent attackers from using open redirects to reach internal resources.
