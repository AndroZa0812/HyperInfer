# Kubernetes Deployment

A Helm chart for Kubernetes deployment is available. See the [Helm chart plan](https://github.com/AndroZa0812/HyperInfer/blob/main/.plan/kubernetes-helm-chart.md) for implementation details.

## Prerequisites

- Kubernetes 1.24+
- Helm 3.x

## Quick Install

```bash
helm repo add hyperinfer https://hyperinfer.github.io/helm-charts
helm install hyperinfer hyperinfer/hyperinfer
```
